# PLAN: terraform-provider-ohauthcat

## Goal
Let developers manage their OhAuthCat environment as code: organizations, their domains, SSO connections, SCIM directories, webhooks, sign-in policies, role assignment rules, portal profiles, branding, log streams and custom domains (product spec C53, decision D32).

## Shape
- **Framework:** HashiCorp Terraform Plugin Framework (protocol 6). No SDKv2.
- **Address:** `registry.terraform.io/ohauthcat/ohauthcat`.
- **Configuration:** `api_key` (sensitive; falls back to `OHAUTHCAT_API_KEY`) and `base_url` (falls back to `OHAUTHCAT_BASE_URL`, default `https://api.ohauthcat.com`). The base URL must be `https`, except loopback hosts for local testing.
- **Client:** `internal/client`, hand-written and fully typed against the pinned spec (`spec/openapi-v1.yaml`, source commit in `spec/PINNED_FROM`). Errors decode the API error envelope (`error.code`, `error.message`, `error.request_id`); a 404 is a typed `NotFound` so resources drop from state when deleted out of band.
- **Resources** (CRUD + import + drift detection through Read):

| Resource | API | Notes |
|---|---|---|
| `ohauthcat_organization` | `/v1/organizations` | `consent_screen` is set by a follow-up PATCH after create |
| `ohauthcat_organization_domain` | `/v1/organizations/{org}/domains` | Read through the list (no single GET); import `org_…/dom_…` |
| `ohauthcat_connection` | `/v1/connections` | SAML by metadata URL, metadata XML or manual values; OIDC by discovery URL; secrets are write-only; delete sends `confirm` |
| `ohauthcat_directory` | `/v1/directories` | SCIM token returned once on create, kept in state as sensitive |
| `ohauthcat_webhook_endpoint` | `/v1/webhook_endpoints` | Signing secret returned once on create |
| `ohauthcat_sign_in_policy` | `/v1/policies` | `config` and `exclusions` update in place |
| `ohauthcat_role_assignment_rule` | `/v1/role_rules` | Removing `condition` sends `clear_condition` |
| `ohauthcat_portal_profile` | `/v1/portal_profiles` | Update is a full replace (PUT) |
| `ohauthcat_branding` | `/v1/branding` | Environment singleton; destroy clears every field |
| `ohauthcat_log_stream` | `/v1/log_streams` | No update route: every change replaces; read through the list |
| `ohauthcat_custom_domain` | `/v1/custom_domains` | No update route: every change replaces |

- **Data sources:** `ohauthcat_organization` (by `id` or `external_id`), `ohauthcat_connection` (by `id`), `ohauthcat_environment` (the API key's environment).
- **Tests:** unit tests drive the real provider through Terraform (`terraform-plugin-testing`, `UnitTest`) against an in-memory fake of the API, covering create, import, out-of-band drift, update and destroy. Acceptance tests are gated by `TF_ACC` and target a local core stack only.
- **Docs:** `docs/` in the Registry layout, generated by `tfplugindocs` from schema descriptions and `examples/`.

## Licence
The provider is the single open-source exception (D32). The owner picks the licence (MPL-2.0 is the ecosystem norm); no `LICENSE` file is committed until then. `THIRD_PARTY_LICENSES` is generated by `make third-party-licenses`.
